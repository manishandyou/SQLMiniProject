# SQLMiniProject
Retail Store Database Management System built using MySQL. This project demonstrates database design, data insertion, filtering, aggregations, joins, subqueries, and set operations on a retail dataset. Developed as part of an SQL Mini Project to analyze customer behavior, sales performance, inventory, and payment trends.

# Retail Store Database Management System

A comprehensive SQL-based Retail Store Database Management System developed using MySQL to manage and analyze retail business operations. The project demonstrates end-to-end database design, data management, and business analytics through a realistic retail dataset.

## Technologies Used

* MySQL Server
* MySQL Workbench
* SQL (DDL, DML, DQL)
* Relational Database Management System (RDBMS)

## Database Components

* Customers
* Products
* Orders
* Order Items
* Payments
* Product Reviews

## Key SQL Concepts Implemented

* Database Creation & Table Design
* Primary Keys & Foreign Keys
* Data Insertion & Management
* Filtering & Sorting
* Aggregate Functions
* GROUP BY & HAVING Clauses
* Multi-Table Joins
* Nested & Correlated Subqueries
* Set Operations (UNION)
* Business Reporting & Analysis

## Business Analysis Performed

* Revenue Analysis
* Customer Purchase Behavior
* Product Performance Tracking
* Inventory Monitoring
* Payment Method Analysis
* Customer Engagement Analysis

## Skills Demonstrated

* Database Design & Normalization
* SQL Query Optimization
* Data Analysis & Reporting
* Problem Solving Using SQL
* Business Intelligence Thinking
* Relational Database Management
* Technical Documentation

## Project Outcome

The project successfully transforms raw retail data into meaningful business insights that can support decision-making related to sales, inventory management, customer retention, and operational efficiency.
